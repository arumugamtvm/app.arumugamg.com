# arumugamg.com Front‑end (React + Vite)

This repository hosts the **React + Vite** front‑end that is deployed on **GitHub Pages** (`https://app.arumugamg.com`).

## Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                    User Browser                             │
│                                                             │
│   ┌─────────────────────────────────────────────────────┐   │
│   │         app.arumugamg.com (React + Vite)            │   │
│   │         Static Site – GitHub Pages                  │   │
│   └──────────────────────┬──────────────────────────────┘   │
│                          │  HTTP (Bearer JWT)                │
└──────────────────────────┼──────────────────────────────────┘
                           │
           ┌───────────────▼───────────────┐
           │   api.arumugamg.com           │
           │   (Cloudflare Worker)         │
           │   GET /status, /todos …       │
           └───────────────┬───────────────┘
                           │  D1 SQL
                           ▼
                   ┌───────────────┐
                   │ Cloudflare D1 │
                   │  (SQLite DB)  │
                   └───────────────┘

Auth flow (separate):
  Browser → mcp.arumugamg.com → OTP email → JWT issued → API calls
```

Data flow: **Front‑end → API (JWT) → D1 DB**  
Auth flow: **MCP (Auth) → JWT → API → D1 DB**
