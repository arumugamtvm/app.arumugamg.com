# arumugamg.com Front‑end (React + Vite)

This repository hosts the **React + Vite** front‑end that is deployed on **GitHub Pages** (`https://app.arumugamg.com`).

## Architecture
- **Static site** – built with Vite and exported as plain HTML/CSS/JS.
- **Premium UI** – dark theme with glass‑morphism, micro‑animations (see `src/index.css`).
- **Consumes the API** – calls `https://api.arumugamg.com/status` (and any future endpoints) to fetch business data.

## Development
```bash
cd app.arumugamg.com
npm install
npm run dev   # http://localhost:5173
```
