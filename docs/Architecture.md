# Architecture – `app.arumugamg.com`

## Overview
- **Framework:** React 19 + Vite (TypeScript)
- **Styling:** Vanilla CSS with a custom design‑system (`src/theme.ts`). Dark theme, glass‑morphism, subtle micro‑animations, Google Font **Inter**.
- **Auth:** Calls **MCP** (`mcp.arumugamg.com`) for OTP/OAuth, receives a signed JWT, stores it in `localStorage`. All API requests include `Authorization: Bearer <JWT>`.
- **Data Flow:** Browser → SPA → **API** (`api.arumugamg.com`) → Cloudflare D1 DB.
- **Error handling:** Central error boundary with toast notifications.
- **Testing:** Jest + React Testing Library covering rendering, mocked API interactions, and auth flow.

## Key Decisions
- **Static‑site build** – Vite outputs a static bundle; deployed to GitHub Pages for global CDN.
- **State Management** – React Context + `useReducer`; avoids extra dependencies.
- **Component Library** – Reusable UI components (`Button`, `Card`, `Modal`) live under `src/components` and use the design‑system tokens.
- **Performance** – Code‑splitting, lazy loading of routes, prefetching of critical assets.
